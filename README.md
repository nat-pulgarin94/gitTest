## :wrench: Instalación

Sigue estos pasos para clonar y poner en marcha el proyecto localmente:

1. **Clona el repositorio**
   ```bash
   git clone https://github.com
   ```

2. **Entra al directorio del proyecto**
   ```bash
   cd nombre-del-proyecto
   ```

3. **Instala las dependencias**
   ```bash
   npm install
   ```

4. **Configura las variables de entorno**
   Crea un archivo `.env` basado en el archivo `.env.example` y añade tus credenciales.

## :handshake: Contribución
¡Las contribuciones son bienvenidas! Por favor, lee las reglas de contribución antes de enviar un Pull Request.
1. Haz un *Fork* del proyecto.
2. Crea tu rama de características (`git checkout -b feature/NuevaFuncionalidad`).
3. Realiza los cambios y haz *Commit* (`git commit -m 'Agrega nueva funcionalidad'`).
4. Sube los cambios (`git push origin feature/NuevaFuncionalidad`).
5. Abre un *Pull Request*.
